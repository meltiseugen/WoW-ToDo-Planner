# Wrath achievement location and guide research

New map payloads among the original 282 gaps: 57.
Original numbered guides: 40 unique achievements, including the supplied Cataclysm example and one encountered Legion comment guide.
Explicit Profit-ending comment matches: 5 achievement IDs.

Comments and corrections are recorded in Data/Sources/CommentAcquisitionGuides.json. Only the compact instructions and destination tables load in WoW.
No scrolling, model-preview or UI code was changed for this research.
Native WoW visual and interaction behavior has not been validated.

Remaining without a fixed payload: 225; 106 have exclusively historical ATT placements. The remainder includes global counters, queued activities and legacy acquisition records. This is not a claim that every remaining record is unobtainable or has been solved.
